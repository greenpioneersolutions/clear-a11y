# Getting help

## Questions

Ask in [GitHub Discussions](https://github.com/greenpioneersolutions/clear-a11y/discussions). That's the place for "how do I...", "why does Clear A11Y report...", setup trouble, and ideas you want to talk through before opening an issue.

## Bugs, false positives and missed issues

Open an issue using one of the [issue forms](https://github.com/greenpioneersolutions/clear-a11y/issues/new/choose):

- **Bug report**: something crashes or behaves wrongly.
- **False positive**: Clear A11Y reported something that isn't an accessibility barrier.
- **Missed issue**: Clear A11Y didn't report a barrier a human found.
- **Rule proposal**: a new check you'd like to see.
- **Feature request**: anything else.

False-positive and missed-issue reports need a minimal HTML reproduction. It becomes a fixture, so the fix is measured.

## Security issues

Never report security issues in public. Follow [SECURITY.md](SECURITY.md).
